# Guess The Number Game

A fun number guessing game written in Python. The user guesses a number between 1 and 100, and the program gives feedback on whether the guess is too high, too low, or correct.

## How to Play:
1. Run the `guess the number.py` script.
2. Enter a number when prompted.
3. The program will tell you if the number is too high, too low, or correct.

## Requirements:
Python 3.x
